Awesome Agent Skills

Where agent skills are published, how to vet one before it runs, and the research behind both · built 2026-10-26

A security-first map of agent skills: the folders of instructions and scripts that Claude Code, Codex, Copilot, Gemini CLI and others load on demand. A skill is code plus instructions, so this catalog starts with how to vet one before it runs.

Every entry was written by someone else and is shown as untrusted text: escaped, never run, and linked with no referrer. Resources marked Speaks to AI agents carry text addressed to AI agents on their pages. Nothing here was installed or executed to build this catalog: third-party scanners read the skills' files as text in a disposable VM or container with no network. A link is not an endorsement.
